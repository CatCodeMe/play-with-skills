# 🧭 导航与布局重设计方案

**创建时间**: 2026-01-17  
**状态**: 🟡 方案评估中  
**目标**: 解决底部导航和顶部入口设计问题，提升专业感

---

## 📌 问题诊断

| 当前问题 | 影响 |
|----------|------|
| 4 Tab 底部导航 (首页/百科/AI/我的) | 传统、功能割裂 |
| AI 被埋在 Tab 里 | 核心功能不突出 |
| 瀑布流首页 | 像社区 App，不像工具 |
| 顶部搜索入口定位模糊 | 用户不清楚能做什么 |

---

## 🎯 设计目标

1. **AI-First**: AI 是核心差异化，应该最显眼
2. **简洁**: 减少 Tab 数量，降低认知负担
3. **聚焦**: 以宠物为中心，不是以功能为中心
4. **专业**: 像工具 App，不像社区 App

---

## 📱 三种方案对比

### 方案 A：AI-First (推荐)

**理念**: AI 是主角，不是配角

**结构**:
```
┌─────────────────────────────────────────┐
│  小美 · 布偶猫                     ⚙️   │  ← 宠物选择器
│  2岁3个月 · 已绝育                      │
├─────────────────────────────────────────┤
│  ┌─────────────────────────────────────┐│
│  │  💬 有什么想问的？                  ││
│  │  ________________________________   ││  ← AI 首位入口
│  │  [拍照] [语音]              发送 ▶  ││
│  └─────────────────────────────────────┘│
│                                         │
│  快捷功能                               │
│  [疫苗] [驱虫] [体重] [日记]            │
│                                         │
│  健康概览                               │
│  ┌─────────────────────────────────────┐│
│  │ 下次驱虫：3月15日 (还有12天)        ││
│  │ 上次体检：1月20日                   ││
│  └─────────────────────────────────────┘│
├─────────────────────────────────────────┤
│        🐾                    👤         │
│       宠物                   我的        │  ← 2 Tab
└─────────────────────────────────────────┘
```

**特点**:
- ✅ 2 个 Tab (宠物/我的)
- ✅ AI 输入框在首页最显眼位置
- ✅ 百科融入 AI 对话
- ✅ 聚焦单只宠物

**适合场景**: AI 功能完善后

---

### 方案 B：卡片仪表盘

**理念**: 像 Apple Health，数据驱动

**结构**:
```
┌─────────────────────────────────────────┐
│  早上好                            👤   │
│  小美今天状态不错 ✨                    │
├─────────────────────────────────────────┤
│  ┌─────────────┐ ┌─────────────┐       │
│  │ 🗓️ 待办     │ │ 📊 体重     │       │
│  │ 驱虫·12天后 │ │ 4.2kg ↑    │       │  ← 数据卡片
│  └─────────────┘ └─────────────┘       │
│                                         │
│  ┌─────────────────────────────────────┐│
│  │ 🤖 AI 助手                     →    ││  ← AI 卡片入口
│  └─────────────────────────────────────┘│
│                                         │
│  ┌─────────────────────────────────────┐│
│  │ 📷 最近照片                         ││
│  │ [img] [img] [img] [+]               ││
│  └─────────────────────────────────────┘│
├─────────────────────────────────────────┤
│     🏠        📚         👤             │
│    首页      发现       我的             │  ← 3 Tab
└─────────────────────────────────────────┘
```

**特点**:
- ✅ 3 个 Tab (首页/发现/我的)
- ✅ 首页是宠物仪表盘
- ✅ AI 是卡片入口
- ✅ "发现"替代"百科"

**适合场景**: 健康数据追踪功能完善后

---

### 方案 C：无底部导航

**理念**: 像 Notion，侧边栏导航

**结构**:
```
┌─────────────────────────────────────────┐
│  🐾 毛孩档案                       ≡    │  ← 汉堡菜单
├─────────────────────────────────────────┤
│                                         │
│  我的宠物                               │
│  ┌─────────────────────────────────────┐│
│  │ 小美 · 布偶猫                   →   ││
│  └─────────────────────────────────────┘│
│  ┌─────────────────────────────────────┐│
│  │ 大黄 · 金毛                     →   ││
│  └─────────────────────────────────────┘│
│  + 添加宠物                             │
│                                         │
│  工具                                   │
│  [AI问答] [疫苗] [驱虫] [体重]          │
│                                         │
│  最近                                   │
│  • AI 对话 - 今天                       │
│  • 体重记录 - 昨天                      │
└─────────────────────────────────────────┘

侧边栏：
┌─────────────┐
│ 首页        │
│ AI 助手     │
│ 健康百科    │
│ ─────────   │
│ 设置        │
└─────────────┘
```

**特点**:
- ✅ 无底部 Tab
- ✅ 侧边栏导航
- ✅ 首页聚焦宠物列表
- ✅ 更现代的导航模式

**适合场景**: 多宠物用户

## 📊 方案对比表

| 维度 | 方案 A | 方案 B | 方案 C |
|------|--------|--------|--------|
| Tab 数量 | 2 | 3 | 0 (侧边栏) |
| AI 位置 | 首页顶部 | 卡片入口 | 工具区 |
| 核心聚焦 | AI 对话 | 数据仪表盘 | 宠物列表 |
| 信息密度 | 中 | 高 | 低 |
| 学习成本 | 低 | 中 | 中 |
| 适合阶段 | AI 为主 | 数据为主 | 多宠物 |
| 参考 App | Raycast | Apple Health | Notion |
