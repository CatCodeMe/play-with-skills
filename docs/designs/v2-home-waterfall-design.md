## 📌 设计目标

将传统工具型首页改造为**瀑布流布局**，增加社区感和内容丰富度，同时保持 AI 工具的核心定位。

---

## 🎯 待确定的设计决策

### 1. 内容类型 (Content Types)

瀑布流中展示哪些内容卡片？

| 选项 | 描述 | 优势 | 劣势 |
|------|------|------|------|
| A. 纯社区内容 | 用户分享的宠物照片/视频 | 社区感强，UGC 驱动 | 冷启动难，需审核 |
| B. 纯知识内容 | 宠物养护文章/小贴士 | 内容可控，工具属性 | 互动性弱 |
| C. 混合内容 | 照片 + 文章 + 小贴士 + 工具卡片 | 内容丰富多样 | 设计复杂度高 |
| D. 智能推荐 | 基于宠物档案的个性化内容 | AI 属性强 | 需要后端支持 |

**当前倾向**: `✅ 方案 C - 混合内容`  
**讨论备注**: 短期先用 Mock 数据实现混合瀑布流，包含：宠物精选照片、养护知识卡片、AI 功能入口、每日小贴士

---

### 2. 卡片设计风格 (Card Style)

| 选项 | 描述 | 视觉效果 |
|------|------|----------|
| A. 小红书风 | 图片占主导 + 底部简短文字 + 圆头像 | 年轻、生活化 |
| B. Pinterest 风 | 纯图片 + 悬浮信息层 | 极简、沉浸 |
| C. 杂志编辑风 | 大标题 + 精选配图 + 摘要 | 精致、专业 |
| D. 温暖插画风 | 配合插画/图标 + 柔和色块 | 亲切、有温度 |

**当前倾向**: `✅ 方案 D+A 融合 - 温暖插画风 + 小红书风`  
**讨论备注**: 图片类内容用小红书风（图大字小），知识/工具类用温暖插画风（色块+图标）。放弃现有渐变配色，重新设计。

---

### 3. 布局结构 (Layout Structure)

现有首页元素如何与瀑布流结合？

```
┌─────────────────────────────────┐
│ 渐变头部 + 问候语                │ ← 保留？简化？
├─────────────────────────────────┤
│ 添加宠物卡片                     │ ← 保留？移到其他位置？
├─────────────────────────────────┤
│ 快捷功能入口                     │ ← 保留？横向滚动？融入瀑布流？
├─────────────────────────────────┤
│                                 │
│      瀑布流内容区域              │ ← 新增
│                                 │
└─────────────────────────────────┘
```

| 元素 | 方案 A (保守) | 方案 B (激进) | 方案 C (混合) ✅ |
|------|---------------|---------------|------------------|
| 渐变头部 | 保留 | 简化为搜索栏 | 极简头部 |
| 添加宠物卡片 | 顶部固定 | 移至"我的"Tab | 瀑布流首卡 |
| 快捷功能 | 保留网格 | 横向滚动条 | 横滑胶囊 |

**当前倾向**: `✅ 方案 C - 混合布局`  
**讨论备注**: 极简头部(搜索+标题+头像) + 横滑胶囊入口 + 瀑布流主体

---

### 4. AI 入口位置 (AI Entry Point)

如何在瀑布流首页中突出 AI 功能？

| 选项 | 描述 | 优势 | 劣势 |
|------|------|------|------|
| A. 独立 Tab | 保持现状 | 清晰、专注 | 不够突出 |
| B. 头部搜索融合 | 搜索框 = AI 入口 | 自然、现代 | 需重新设计头部 |
| C. 瀑布流穿插 | AI 卡片定期出现在信息流中 | 曝光高 | 可能打扰用户 |
| D. 底部常驻栏 | 类似 ChatGPT 的输入框 | 随时可用 | 占用屏幕空间 |
| E. 智能触发 | 识别用户意图后弹出 | 不打扰 | 技术复杂 |
| **F. 三重入口** | 搜索框+瀑布流卡片+Tab | 多触点、无处不在 | 需要协调设计 |

**当前倾向**: `✅ 方案 F - 三重入口组合`  
**讨论备注**: ① 头部搜索框("问问AI...") ② 瀑布流AI功能卡片 ③ 底部AI Tab

---

### 5. 卡片尺寸比例 (Card Dimensions)

| 选项 | 列数 | 卡片比例 | 适合内容 |
|------|------|----------|----------|
| A. 标准双列 | 2 | 3:4 | 方形/竖图 |
| B. 错落双列 | 2 | 随机高度 | 多样内容 |
| C. 紧凑三列 | 3 | 1:1 | 大量内容 |
| D. 混排布局 | 混合 | 大卡 + 小卡 | 突出重点 |

**当前倾向**: `✅ 方案 B - 错落双列`  
**讨论备注**: 高度随内容自适应，视觉有节奏感，小红书/Pinterest成熟方案

## 🔄 V3 设计迭代 (2026-01-17)

### 用户反馈
- ❌ 渐变色有明显的 AI 感
- ❌ 间距系统不专业
- ❌ 视觉层次不够丰富

### 新设计方向
- 🖼️ 用**图片/图文**代替渐变背景
- 📐 建立**专业的间距系统** (8px 基准)
- 🎨 纯色 + 图片为主的视觉风格
- 📷 首页使用**大图 Hero** 或**图文卡片**

### ✅ V3 最终方案：Hero + 杂志 + 卡片墙融合

```
┌─────────────────────────────────────────────┐

│                                             │
├─────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────┐ │
│ │                                         │ │
│ │      🐱 Hero 大图区域                   │ │  ← 精选宠物图/用户宠物
│ │      (圆角, 带底部渐变遮罩)             │ │
│ │                                         │ │
│ │  ┌────────────────────────────────────┐ │ │
│ │  │ 早上好，铲屎官 👋                   │ │ │  ← 叠加在图片上
```

### 视觉细节

| 元素 | 设计 |
|------|------|
| 头部 | 纯白背景，无渐变 |
| Hero 图 | 圆角 20px，底部半透明渐变遮罩（显示文字） |
| 快捷入口 | 白底胶囊，细边框，图标+文字 |
| 精选大卡 | 图片 + 标题 + 摘要，满宽 |
| 瀑布流 | 不均匀高度，偶尔大卡打破节奏 |
| 间距 | 严格 8px 网格系统 |

### 间距规范 (8px Grid)

```
xs:  4px   // 图标与文字
sm:  8px   // 紧凑元素
md:  16px  // 卡片内边距
lg:  24px  // 区块间距
xl:  32px  // 大区块
2xl: 48px  // 页面级
```

### 卡片类型 (Card Types)

| 类型 | 样式 | 内容 |
|------|------|------|
| **图片卡** | 图片主导 + 底部文字 | 宠物照片、用户分享 |
| **知识卡** | 色块背景 + 图标 + 标题 | 养护贴士、百科文章 |
| **AI功能卡** | 渐变背景 + 图标 + CTA | 拍照识别、智能问答 |
| **工具卡** | 图标 + 简短描述 | 疫苗提醒、健康档案入口 |
