## 📊 Part 1: 电商联盟 API 详细分析

### 1.1 各平台 API 能力对比

| 平台 | 功能 | 个人开发者支持 | 申请条件 |
|------|------|---------------|----------|
| **淘宝联盟** | 商品搜索、价格、佣金、推广链接、订单跟踪 | ✅ 支持 | 需备案网站/App |
| **京东联盟** | 商品搜索、价格、佣金、推广链接、订单查询 | ✅ 基础支持 | 注册开发者账号 |
| **拼多多·多多进宝** | 商品搜索、推广链接 | ✅ 支持 | 注册账号 |
| **抖音精选联盟** | 商品推广、佣金 | ⚠️ 需达人身份 | 粉丝门槛 |

### 1.2 淘宝联盟 API（最完善）

**核心能力**：
- `taobao.tbk.item.info.get` - 商品详情（标题、价格、图片）
- 商品搜索 API - 关键词搜索+筛选排序
- 高佣转链 API - 生成带佣金的推广链接
- 订单明细 API - 跟踪成交获取佣金

**申请流程**：
1. 注册淘宝联盟账号
2. 备案网站或 App（小程序需提供备案信息）
3. 在阿里开放平台申请 AppKey + AppSecret
4. 创建推广位 ID (adzoneID)
5. 开始调用 API

**限制**：
- 默认每日 10 万次调用（可申请提升）
- AppKey、备案网站、推广位 ID 必须配套使用

### 1.3 京东联盟 API

**核心能力**：
- `jd.union.open.goods.query` - 商品搜索（关键词、SKU、分类）
- 商品详情查询 - 名称、价格、图片
- 推广链接生成 - 单品/二合一链接
- 订单查询 - 90天内订单和佣金

**申请流程**：
1. 注册京东联盟账号
2. 在京东开放平台创建应用
3. 申请 API 权限（需说明用途）
4. 获取 AppID + AppKey

**注意**：部分高级 API 需要额外申请权限（邮件申请）

### 1.4 抖音电商 API（复杂）

**结论**：**暂不建议接入**

| 问题 | 说明 |
|------|------|
| 门槛高 | 达人带货需要粉丝门槛（1000有效粉丝起） |
| 定位不同 | 抖音主要是内容电商，不是比价场景 |
| API 限制 | 商品 API 主要面向商家和服务商，非个人 |

**替代方案**：后期如果用户量大，可以考虑接入，但 MVP 阶段不建议。

### 1.5 API 能否满足你的需求？

| 你的需求 | 淘宝联盟 | 京东联盟 | 是否满足 |
|----------|----------|----------|----------|
| 商品搜索 | ✅ | ✅ | ✅ 满足 |
| 价格查询 | ✅ | ✅ | ✅ 满足 |
| 历史价格 | ❌ 不提供 | ❌ 不提供 | ⚠️ 需自己存储 |
| 推广链接 | ✅ | ✅ | ✅ 满足 |
| CPS 分佣 | ✅ | ✅ | ✅ 满足 |
| 成分信息 | ❌ | ❌ | ⚠️ 需 AI 解读 |

**历史价格方案**：官方 API 不提供历史价格，需要自己定时抓取并存储价格数据。

## 📱 Part 2: 小程序推广问题

### 微信会帮你推广吗？

**简短回答**：**不会主动推广**，但提供流量入口。

| 入口 | 说明 | 你需要做的 |
|------|------|-----------|
| **微信搜索** | 用户搜索关键词可能展示 | 优化小程序名称和描述 |
| **附近的小程序** | 展示附近的小程序 | 不适用于工具型 |
| **分享/二维码** | 用户分享传播 | 做好分享功能+海报 |
| **公众号关联** | 公众号菜单/文章跳转 | 需要有公众号 |
| **付费广告** | 朋友圈/公众号广告 | 需要付费 |

### 冷启动获客策略（免费）

| 阶段 | 策略 | 成本 |
|------|------|------|
| **Phase 1** | 朋友圈发起测试，邀请养宠朋友试用 | 免费 |
| **Phase 2** | 小红书发"宠物食品成分解读"内容，文末引导到小程序 | 时间 |
| **Phase 3** | 产品内分享功能：解读结果生成图片，分享到微信群 | 免费 |
| **Phase 4** | 微信群运营：建立用户群，收集反馈 | 时间 |

## 🎨 Part 3: 工具型 UI 利弊分析

你选择了**工具型设计**（类似什么值得买、慢慢买）。

### 工具型 UI 特点

| 特点 | 示例 |
|------|------|
| 信息密度高 | 同屏展示更多商品/数据 |
| 功能导向 | 突出搜索、比价、筛选等核心功能 |
| 色彩克制 | 以中性色为主，强调数据 |
| 交互高效 | 减少动画，操作路径短 |

### 利弊分析

| 维度 | 优点 | 缺点 |
|------|------|------|
| **用户认知** | 一看就知道是工具，专业感强 | 不够"有趣"，可能缺乏情感连接 |
| **开发效率** | 组件标准化，复用性高 | - |
| **信息传达** | 数据展示清晰，比价一目了然 | 信息过多可能造成认知负担 |
| **差异化** | 能凸显核心价值（比价+AI解读） | 视觉上不容易脱颖而出 |
| **目标用户** | 适合"效率优先"的用户 | 不适合追求"体验/情感"的用户 |

### 设计方向

**"专业但不冰冷"的工具型设计**：

1. **核心**：功能导向，信息密度高
2. **点缀**：适度使用品牌色（暖色系），增加亲和力
3. **细节**：微妙的阴影和圆角，避免过于生硬
4. **焦点**：AI 解读结果用卡片形式突出展示

**参考产品**：
- 什么值得买（信息密度）
- 慢慢买（价格曲线展示）
- 丁香医生（AI 解读的可信展示）

## ✅ Part 4: 开发与上线完整清单

### 4.1 开始开发前需要准备

| 准备项 | 说明 | 获取方式 |
|--------|------|----------|
| **微信公众平台账号** | 用于注册小程序 | mp.weixin.qq.com 注册 |
| **小程序账号（个人）** | 上传代码和提交审核 | 微信公众平台注册 |
| **AppID** | 小程序唯一标识 | 注册后自动获得 |
| **微信开发者工具** | 本地开发和调试 | 微信官方下载 |
| **AI API** | 调用 LLM 做成分解读 | Claude/GPT/文心一言 API |
| **服务器** | 后端接口（可选） | 云函数或自建 |
| **域名+HTTPS** | 小程序要求 HTTPS | 阿里云/腾讯云 |

### 4.2 技术选型建议

| 层级 | 推荐方案 | 理由 |
|------|----------|------|
| **前端** | Taro + React | 你熟悉 React，Taro 支持小程序 |
| **UI 框架** | NutUI 或 Taro UI | 专为小程序优化 |
| **后端** | 微信云开发（云函数） | 免服务器，个人开发者友好 |
| **数据库** | 微信云数据库 | 与云函数配套 |
| **AI** | Claude API 或 文心一言 | 成分解读 |

**优势**：使用微信云开发可以避免自建服务器和备案域名。

### 4.3 小程序上线流程（详细）

```
Step 1: 注册小程序
├── 访问 mp.weixin.qq.com
├── 选择"小程序" → "个人"
├── 提交身份证信息+人脸识别
└── 获取 AppID

Step 2: 小程序备案（必须！）
├── 在小程序后台点击"去备案"
├── 填写主体信息（身份证正反面）
├── 填写小程序信息
├── 人脸核身
├── 等待微信初审（1-2 工作日）
├── 工信部短信核验（24小时内完成）
└── 等待通管局审核（1-20 工作日）
⚠️ 备案未完成无法上线！

Step 3: 开发
├── 下载微信开发者工具
├── 创建 Taro 项目
├── 开发核心功能
├── 本地调试
└── 上传代码包

Step 4: 代码审核
├── 填写版本描述
├── 提交审核（1-3 工作日）
├── 若被拒：根据反馈修改后重新提交
└── 审核通过后可发布

Step 5: 发布上线
├── 点击"发布"
└── 用户可通过微信搜索/分享访问
```

### 4.4 审核注意事项

| 常见拒绝原因 | 如何避免 |
|-------------|----------|
| 内容不合规 | 不涉及敏感内容 |
| 功能不完整 | 确保所有页面可访问 |
| 类目不符 | 选择正确的服务类目 |
| 需要资质 | 工具类一般不需要特殊资质 |
| 隐私政策缺失 | 添加隐私政策页面 |

**个人小程序推荐类目**：工具 > 效率工具

- [ ] 小程序注册完成
