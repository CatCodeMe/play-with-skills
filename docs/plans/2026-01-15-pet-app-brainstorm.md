## ✅ 已确定的方向

### 1. 核心场景
- **社交社区 (B)** - 和其他宠物主人互动、分享、交流经验
- **健康管理 (C)** - 疫苗提醒、驱虫周期、常见病预防等

### 2. 分享机制
- 支持多种分享范围（用户自选）:
  - 仅限好友/家人
  - 兴趣圈子/群组
  - 链接分享

### 3. 健康功能规划
- **初期实现**: 提醒 + 科普 + 健康档案
- **未来预留**: AI 智能诊断能力（架构需预留）

### 4. 差异化设计 - 块结构编辑器
- 灵感来源: Notion
- 目的: 
  - 让用户按自己的习惯自定义界面布局
  - 降低使用门槛
  - 激发分享欲望
- 用户可以用不同的「块」搭建宠物主页：
  - 照片墙块
  - 健康档案块
  - 疫苗时间线块
  - 今日心情块
  - 等等...

### 5. 技术选型
- **React Native + Expo**: 对新手友好，配置简单，可快速预览
- **TypeScript**: 用户有 TS 经验，增加类型安全
- 用户背景: Java 为主，TypeScript 有了解，App 开发新手
