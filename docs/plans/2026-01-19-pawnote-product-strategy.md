## 📌 Part 1: 产品定位确定

### 核心定位

> **"宠选" - AI 驱动的宠物食品购物助手**
> 
> 帮你看成分、比价格、避坑省钱

### 目标用户

**"懒人"宠物主**：
- 关心毛孩健康，但没时间研究
- 在多个平台比价很累
- 希望有人告诉我"这个产品到底好不好"
- 愿意为省时间付费

### 核心价值主张

| 用户痛点 | 我们的解决方案 |
|----------|---------------|
| 产品成分看不懂 | **AI 成分解读**：拍照即可获得专业解读 |
| 多平台比价累 | **一键比价**：整合淘宝/京东/拼多多价格 |
| 不知道是否虚假促销 | **历史价格**：识别"先涨后降" |
| 忘记补货 | **复购提醒**：智能提醒该买了 |
| 降价错过 | **降价提醒**：关注商品降价时通知 |

### 差异化竞争点（vs 什么值得买）

| 维度 | 什么值得买 | 宠选 |
|------|-----------|------|
| 定位 | 全品类 | 宠物垂直 |
| 核心功能 | 优惠信息聚合 | **AI 成分解读** |
| 内容模式 | UGC（需运营） | AI 驱动（自动化） |
| 用户体验 | 信息过载 | 精简聚焦 |

## ⚠️ Part 2: 风险评估与规避

### 2.1 爬虫法律风险（严重）

**调研结论**：直接爬取电商平台数据**法律风险极高**！

| 风险类型 | 具体内容 | 严重程度 |
|----------|----------|----------|
| **不正当竞争** | 《网络反不正当竞争暂行规定》(2024.9.1) 明确禁止非法获取他人数据 | ⭐⭐⭐⭐⭐ |
| **刑事风险** | 2021年有人因爬取11亿条淘宝数据被判刑 | ⭐⭐⭐⭐⭐ |
| **民事赔偿** | 近期判例：爬取淘宝数据被判赔500万 | ⭐⭐⭐⭐⭐ |

**违法行为特征**（避免触碰）：
1. 突破反爬虫措施（验证码、IP限制等）
2. 大规模商业化利用数据
3. 对原平台构成实质性替代
4. 未获授权

### 2.2 合规解决方案

**✅ 推荐方案：使用官方开放 API + 第三方合规服务**

| 方案 | 说明 | 合规性 |
|------|------|--------|
| **淘宝联盟 API** | 淘宝官方开放平台，获取商品信息+返佣 | ✅ 完全合规 |
| **京东联盟 API** | 京东官方开放平台 | ✅ 完全合规 |
| **拼多多开放平台** | 多多进宝 API | ✅ 完全合规 |
| **聚合比价 API** | 如"比价狗"等第三方合规服务 | ⚠️ 需审核对方资质 |

**使用官方联盟 API 的好处**：
- 完全合规，平台鼓励
- 可以获得 CPS 分佣（商业模式）
- 数据准确、实时

**需要条件**：
- 淘宝联盟：需要备案网站或 App
- 京东联盟：需要企业资质申请高级权限
- 拼多多：个人可申请，但权限有限

### 2.3 小程序主体选择

**调研结论**：个人小程序**无法开通微信支付**！

| 维度 | 个人主体 | 企业主体 |
|------|----------|----------|
| **微信支付** | ❌ 不支持 | ✅ 支持 |
| **微信认证** | ❌ 不支持 | ✅ 支持 (300元/年) |
| **高级功能** | 受限 | 完整 |
| **电商能力** | ❌ 无法交易 | ✅ 完整支持 |
| **可信度** | 低 | 高 |
| **注册数量** | 最多5个 | 最多50个 |

**结论**：如果要做 CPS 分佣（需要跳转购买），个人主体勉强可以；但如果要做 VIP 付费订阅，**必须企业主体**。

## 🤔 Part 3: 需要回答的关键问题

### 问题 1：是否成立公司？

| 选择 | 好处 | 坏处 |
|------|------|------|
| **不成立** | 零成本启动，先验证需求 | 无法开通支付、联盟权限受限、可信度低 |
| **成立个体工商户** | 成本低(约500元)、可开通支付 | 财务/税务责任 |
| **成立有限公司** | 完整资质、责任有限 | 成本高(约3000元)、维护成本 |

**我的建议**：
- **Phase 1**：先用个人主体上线 MVP，验证需求（只做 AI 成分解读，跳转到电商 App）
- **Phase 2**：如果有用户留存，再注册个体工商户，开通支付和联盟
- **Phase 3**：如果业务增长，再考虑成立公司

### 问题 2：冷启动与信任建立

你提到的"冷启动"和"信任"问题非常关键！

**信任建立策略**：

| 策略 | 具体做法 |
|------|----------|
| **透明开源** | AI 解读逻辑公开，用户可以看到判断依据 |
| **用户反馈闭环** | 解读结果支持用户纠正，持续改进 |
| **不推销** | 明确承诺：不收品牌钱，不"恰饭"推荐 |
| **数据来源标注** | 每个价格标注来自哪个平台、什么时间 |
| **社区验证** | 用户可以对解读结果投票"准确/不准确" |

**冷启动策略**：

| 阶段 | 策略 |
|------|------|
| **种子用户** | 从你自己的社交圈开始（养宠朋友） |
| **内容种草** | 在小红书发"宠物食品成分解读"内容，引流 |
| **工具价值** | 先做好核心功能（AI 解读），让产品自己说话 |
| **口碑传播** | 产品内加分享功能，解读结果可分享到微信 |

### 问题 3：共享共治思路

你提到希望融入"共享共治"，让用户参与决策，这个很好！

**可落地的方案**：

| 机制 | 说明 |
|------|------|
| **功能投票** | 每月发起投票，让用户选择下一个开发的功能 |
| **成分数据贡献** | 用户可以提交新产品的成分信息，平台审核后入库 |
| **解读纠错** | 用户可以反馈 AI 解读错误，获得积分奖励 |
| **食品测评众筹** | 用户众筹购买某产品，全透明测评 |
| **开放路线图** | 公开产品开发计划，GitHub 式的 issue 管理 |

## 🛠 Part 4: MVP 功能规划

### Phase 1：最小可行产品（1-2个月）

**目标**：验证"AI 成分解读"是否有价值

| 功能 | 描述 | 优先级 |
|------|------|--------|
| **AI 成分解读** | 拍照/输入配料表，获得 AI 解读 | P0 |
| **解读结果分享** | 生成图片分享到微信 | P0 |
| **历史记录** | 保存解读过的产品 | P1 |
| **用户反馈** | 解读结果评价（准确/不准确） | P1 |

**不做**：比价（需要联盟 API）、支付功能

**技术栈**：H5 网页 + 小程序 webview 套壳

### Phase 2：增加比价能力（第3-4个月）

**前提**：注册个体工商户，申请电商联盟

| 功能 | 描述 | 优先级 |
|------|------|--------|
| **多平台比价** | 接入淘宝/京东联盟 API | P0 |
| **历史价格曲线** | 展示价格走势 | P0 |
| **购买跳转** | CPS 链接跳转到电商 App | P0 |
| **降价提醒** | 微信模板消息推送 | P1 |

**商业模式启动**：CPS 分佣

### Phase 3：增强粘性（第5-6个月）

| 功能 | 描述 |
|------|------|
| **复购提醒** | 根据购买周期智能提醒 |
| **收藏夹** | 关注商品管理 |
| **VIP 订阅** | 解锁更多功能 |
| **共治机制** | 功能投票、数据贡献 |
